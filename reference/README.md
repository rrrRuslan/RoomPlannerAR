# reference/

`reference/ios-app` — старий iOS-додаток (Swift, ARKit, RoomPlan) як read-only git submodule. Він лише референс поведінки: агенти читають код, але не змінюють його і не переносять архітектуру ([docs/PROJECT.md](../docs/PROJECT.md), розділ 2.1).

Референсна версія фіксується тегом `reference-v1` у репозиторії iOS-додатку; submodule вказує на цей коміт і далі не оновлюється.

> Submodule ще не підключено: потрібна адреса репозиторію iOS-додатку.
